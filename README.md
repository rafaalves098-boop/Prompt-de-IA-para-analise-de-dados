# Prompt-de-IA-para-analise-de-dados
O Prompt é um desafio do Bootcamp da DIO. O desafio é criar um comando para uma IA generativa. Minha ideia foi de criar uma ferramenta de análise de feedback direcionado para agências bancarias. O trabalho da IA é analisar os feedbacks e criar resumos com insights claros e acionáveis.
